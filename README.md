# 卡丘大转盘

用来给《卡拉彼丘》爆破模式随机抽一套进攻、一套防守：角色、觉醒、副武器、近战，再加两个投掷道具。

目前名单按游戏 **26SP4** 版本整理。

## 怎么玩

把仓库下载下来，用浏览器打开 `index.html` 即可。

1. 点 **START** 开始转，再点 **STOP** 停下来，两边配装一起定好
2. 点角色头像可以换人：觉醒会跟着换，枪和道具不动

规则很简单：

- 进攻只从「剪刀手 + 乌尔比诺」里抽
- 防守只从「欧泊 + 乌尔比诺」里抽
- 同一轮进攻和防守不会抽到同一个人
- 觉醒只会出 2 或 3，不会两个都带
- 每边两个道具不重复
- 主武器跟着角色，不用另抽
- 晶源体不参加（爆破模式选不到他们）

## 这些文件是干什么的

| 文件 | 干什么 |
| --- | --- |
| `index.html` | 网页本身，双击就能开 |
| `data.js` | 角色和武器名单，出新角色主要改这里 |
| `app.js`、`style.css` | 转盘怎么转、长什么样 |
| `assets/portraits/` | 角色头像 |
| `assets/bg/` | 进攻、防守两边的背景图 |
| `launcher.py` | 用来做成 Windows 里能双击的程序 |
| [后续更新说明.md](后续更新说明.md) | 游戏更新后，怎么加新角色、新武器，以及怎么重新做成能双击的程序 |

## 游戏出了新角色怎么办

打开 `data.js`，在名单里加一条，再把头像图片放到 `assets/portraits/` 文件夹，名字和角色编号一致。新枪、新近战、新道具也是改 `data.js` 里对应那几段。

名字请对照游戏或 Wiki，不要自己编。

改完后，刷新浏览器里的页面就能看到。如果你平时用的是「卡丘大转盘.exe」这个双击程序，还要按 [后续更新说明](后续更新说明.md) 重新做一次程序，否则双击的还是旧名单。
